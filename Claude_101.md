# Effective Prompting

## Prompt Formula

```
Context
+ Task
+ Rules
= Better Output
```

### Context

### Task
What should Claude do?

### Rules

- Talk naturally

# Important Insights 💡

### 1. Claude is not just an LLM.
Think of it as an **AI operating system** with different capabilities:
- Chat
- Research
- Coding
- Projects
- Skills
- Connectors

---

### 2. Better Context = Better Output

Claude performs best when it knows:
- Your goal
- Your constraints
- Your files
- Your preferred style

---

### 3. Prompting is Conversation

Don't expect perfection in one prompt.

```
Prompt
    ↓
Response
    ↓
Feedback
    ↓
Refined Response
```

Iterative prompting is the intended workflow.

---

### 4. Projects + Skills = Powerful Combination

Projects answer:

> **What information should Claude know?**

Skills answer:

> **How should Claude perform the task?**

---

### 5. Connectors unlock Claude's full potential

Without connectors:
- Claude works from your prompt.

With connectors:
- Claude works from your **real data**.

---

### 6. Use the Right Tool

| Need | Feature |
|------|---------|
| Quick question | Chat |
| Long-term work | Projects |
| Repeatable workflow | Skills |
| Company knowledge | Enterprise Search |
| Multi-source investigation | Research |
| External apps | Connectors |
| Reusable outputs | Artifacts |
| Coding | Claude Code |

---

### 7. Golden Rule

> **Claude is most powerful when treated as a collaborator, not a search engine.**

Give it:
- Context
- Goals
- Constraints
- Feedback

Then iterate until you get the desired result.
